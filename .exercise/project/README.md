# Palmer penguins

`analyze.py` reads `data/penguins.csv`, the 2007 field season, and computes male minus female mean body mass for each species, in grams. It prints the three numbers and writes them to `metrics.json`.

```bash
python analyze.py
```

- `environment.yml` lists the packages for conda.
- `pyproject.toml` lists the packages for uv.

Data: palmerpenguins (Horst, Hill and Gorman 2020, doi:10.5281/zenodo.3960218), CC0, from Gorman, Williams and Fraser (2014), PLOS ONE 9(3): e90081. Collected by Palmer Station LTER with NSF support.
