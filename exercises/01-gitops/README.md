# GitOps: how fast is CO2 rising?

Open the notebook and follow it. Short path, about 15 minutes: step 1, then `python check.py --short`. The full exercise takes about 30 minutes.

[Open in Binder](https://mybinder.org/v2/gh/ohpcsim/reproducibility-in-ai/binder-01-gitops?urlpath=lab/tree/gitops.ipynb), or run it on your laptop on Linux, macOS, or Windows through WSL2:

```bash
conda env create --file environment.yml
conda activate repro-gitops
jupyter lab gitops.ipynb
```

`python check.py` runs the full check.
