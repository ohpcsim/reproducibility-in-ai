# GitOps: how fast is CO2 rising?

Short path, about 15 minutes: step 1 and its check. The full exercise takes about 30 minutes. The instructions are in `gitops.ipynb`, or on the site.

[Open in Binder](https://mybinder.org/v2/gh/ohpcsim/reproducibility-in-ai/binder-01-gitops?urlpath=lab/workspaces/exercise) for a terminal and the instructions side by side. Or use your own terminal on Linux, macOS, or Windows through WSL2:

```bash
conda env create --quiet --file .binder/environment.yml
conda activate repro-gitops
python scripts/setup_project.py
cd project
```

Run `python ../check.py` from `project` to check your work.
