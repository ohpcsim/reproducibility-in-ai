# DataOps: a new field season arrives

Does a new field season change how body mass tracks flipper length in penguins?

Open the notebook and follow it. Short path, about 15 minutes: the setup cells and step 1, then `python check.py --short`. The full exercise takes about 35 minutes.

[Open in Binder](https://mybinder.org/v2/gh/ohpcsim/reproducibility-in-ai/binder-02-dataops?urlpath=lab/tree/dataops.ipynb), or run it on your laptop on Linux, macOS, or Windows through WSL2:

```bash
conda env create --file environment.yml
conda activate repro-dataops
jupyter lab dataops.ipynb
```

`python check.py` runs the full check.
