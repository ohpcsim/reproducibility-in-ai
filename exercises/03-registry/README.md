# Model registry: which digit classifier should we promote?

Open the notebook and follow it. Short path, about 15 minutes: the setup cells and step 1, then `python check.py --short`. The full exercise takes about 40 minutes.

[Open in Binder](https://mybinder.org/v2/gh/ohpcsim/reproducibility-in-ai/binder-03-registry?urlpath=lab/tree/registry.ipynb), or run it on your laptop on Linux, macOS, or Windows through WSL2:

```bash
conda env create --file environment.yml
conda activate repro-registry
jupyter lab registry.ipynb
```

`python check.py` runs the full check.
