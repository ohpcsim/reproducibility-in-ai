# 3. Versioning data: do the 2008 and 2009 seasons change how much heavier male penguins are?

About 15 minutes. The instructions are in `dataops.ipynb`, or on the site.

[Open in Binder](https://mybinder.org/v2/gh/ohpcsim/reproducibility-in-ai/binder-03-dataops?urlpath=lab/workspaces/exercise) for a terminal and the instructions side by side. Or use your own terminal on Linux, macOS, or Windows through WSL2:

```bash
conda env create --quiet --file .binder/environment.yml
conda activate repro-dataops
python scripts/setup_project.py
cd project
```

Run `python ../check.py` from `project` to check your work.
